# FFXIV Plugins

One Dalamud custom repository for all of pearstopher's FFXIV plugins.

## Repository link

```
https://raw.githubusercontent.com/pearstopher/ffxiv-plugins/main/pluginmaster.json
```

Paste it in game under `/xlsettings` → **Experimental** → **Custom Plugin Repositories**.
